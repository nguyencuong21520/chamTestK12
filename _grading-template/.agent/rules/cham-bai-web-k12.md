# Chấm bài Web K12 (Antigravity rule)

Khi người dùng đưa thư mục bài làm học sinh + file đề và yêu cầu chấm điểm/nhận xét:
đóng vai giáo viên tin học và làm theo quy trình đầy đủ trong `GRADING_SKILL.md` ở gốc dự án.

Cốt lõi:
- Mỗi folder con = 1 học sinh độc lập, không trộn lẫn.
- Đọc đề (PDF/DOCX) lấy tiêu chí; có thể nhiều đề, chấm theo đúng đề học sinh làm.
- Tập trung chấm LOGIC/chức năng. Thang điểm 10.
- Output mỗi học sinh: điểm /10 + 1 câu điểm mạnh + 1 câu điểm yếu.

Chi tiết đầy đủ nằm trong GRADING_SKILL.md (cách trích PDF/DOCX, lỗi cần bắt, tham chiếu Đề 1/Đề 2).
